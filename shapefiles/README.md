# Shapefiles

This folder contains small synthetic WGS84 teaching shapefiles:

- `admin_boundaries`: polygon administrative districts inspired by common GADM-style boundary workflows, but not copied from GADM.
- `osm_places`: town points and road lines inspired by OpenStreetMap/Geofabrik workflows, but not copied from OSM.
- `health_facilities`: health facility points inspired by healthsites.io workflows, but synthetic.

Synthetic layers are used so the repository can be freely redistributed and run offline in JupyterLite.
